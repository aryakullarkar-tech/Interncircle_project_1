INTERN CIRCLE - PROJECT 01
Personal Portfolio Landing Page

FILES
- index.html : Semantic HTML structure and small mobile navigation script
- style.css  : Responsive styling using Flexbox, Grid and media queries

HOW TO RUN
1. Keep index.html and style.css in the same folder.
2. Open index.html in Chrome, Edge or Firefox.
3. Optional: Open the folder in VS Code and use the Live Server extension.

BEFORE SUBMISSION
1. Replace the sample email address (your-email@example.com) with your own email.
2. Add your GitHub, LinkedIn and other social profile links if you have them.
3. Check the page at mobile (360px), tablet (768px) and desktop (1280px) widths.
4. Publish the folder using GitHub Pages.
5. Submit the live page link, GitHub repository link and a short design note on InternCircle.

DESIGN NOTE (you can use or edit this)
I chose a navy and blue colour palette to create a clean, professional look.
I used CSS Grid for the skills and project cards, Flexbox for navigation and
content alignment, and media queries to make the page responsive on mobile.
The code preview and project mockups are CSS illustrations, so no image files
are required.
